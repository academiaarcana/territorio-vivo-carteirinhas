# Impressão acessível — checklist por tela + biblioteca visual

## Princípio central

O apoio visual do Território Vivo não é decoração. A pergunta de validação é:

> Se o texto fosse escondido, a imagem ajudaria a pessoa a entender o que precisa acontecer ou fazer?

Quando a imagem não comunica uma ação, um serviço, um preparo, um local ou um público de forma suficientemente concreta, ela não deve ser usada como substituta do texto. O texto simples continua presente como reforço.

## Modos de impressão padronizados

Toda impressão deve considerar os mesmos quatro recursos:

- **Leitura fácil** — frases mais curtas, hierarquia simples e menos densidade visual.
- **Apoio visual** — pictogramas específicos e funcionais associados ao conteúdo real.
- **Letra ampliada** — tipografia maior, mais espaço e menor densidade por folha.
- **Econômica** — menos fundos e menor consumo de tinta sem perder contraste essencial.

## Checklist por tela

### 1. Carteirinhas

Prioridade de apoio visual: **muito alta**.

Checklist técnico — `[x]` indica implementação e contrato automatizado; a inspeção humana do PDF continua registrada separadamente:

- [x] Nome/referência: pessoa ou família quando isso ajudar a identificação.
- [x] Data: calendário como reforço; a data numérica continua obrigatória.
- [x] Hora: relógio como reforço; a hora numérica continua obrigatória.
- [x] Local: imagem concreta da UBS, casa, escola ou outro local reconhecível quando o conteúdo permitir.
- [x] Serviço: imagem específica para consulta, vacina, dentista, exame/coleta, pré-natal, curativo ou medicamento.
- [x] Preparo: imagens específicas para jejum, água, documento, Cartão SUS, exames/resultados, medicamento, acompanhante e chegada antecipada.
- [x] Avisos: risco/barreira apenas quando o texto realmente tratar de risco ou acesso.
- [x] Lote: cada posição mantém conteúdo independente e temporário.
- [x] Letra ampliada e apoio visual não devem ser comprimidos em miniaturas ilegíveis.

Validação prática: em **Meu Próximo Atendimento**, a pessoa deve conseguir reconhecer visualmente o motivo da ida e os preparos principais antes de ler os detalhes.

- [ ] Inspeção humana do PDF preenchido com data, hora, local, serviço e preparos, sem cortes ou pictogramas ambíguos.

### 2. 5 minutos do território

Prioridade de apoio visual: **média** — é material de equipe, não comunicação principal com usuário.

Checklist:

- [x] Quem/onde: pessoa, família, local ou referência quando reconhecível.
- [x] Achado/mudança: risco, barreira, parceiro, visita ou outro significado concreto quando detectável.
- [x] Decisão: pictograma de ação/próximo passo.
- [x] Responsável/retorno: pessoa/equipe como reforço, sem substituir o nome.
- [x] Revisar: calendário.
- [x] Evitar excesso de figuras; o objetivo é leitura rápida da equipe.

### 3. Indicadores

Prioridade de apoio visual: **baixa a média** — apoio à leitura, nunca substituição do número.

Checklist:

- [x] População/pessoas: grupo de pessoas.
- [x] Pessoas idosas: pessoa idosa.
- [x] Gestantes: gestante.
- [x] Hipertensão: símbolo específico de pressão arterial.
- [x] Diabetes: símbolo específico de glicemia/diabetes.
- [x] Próxima ação: ação/encaminhamento.
- [x] Números permanecem grandes e explícitos; pictograma não representa quantidade.
- [x] Não transformar indicadores em ranking ou sinalização moral de desempenho.

### 4. Educação em saúde

Prioridade de apoio visual: **muito alta**.

Checklist:

- [x] Cada orientação importante deve ter uma imagem relacionada à ação concreta, quando houver pictograma adequado.
- [x] Sequências devem seguir a ordem em que a pessoa executa os passos.
- [x] Evitar símbolo genérico de saúde quando existe uma imagem específica.
- [x] Preparos e cuidados devem usar imagens concretas: mãos, água, medicamento, aplicação, descarte etc.
- [x] Informações que dependem de valor exato, dose, data, hora ou medida continuam escritas.
- [x] Apoio visual não deve alterar prescrição, dose, diagnóstico ou orientação clínica individual.
- [x] Fontes e avisos técnicos continuam disponíveis no impresso.

## Regras de uso

1. **Especificidade vence genericidade.** “Vacina” usa vacina, não uma cruz médica genérica.
2. **O conteúdo preenchido participa da escolha.** Um campo chamado “Serviço” deve mostrar vacina se o usuário escreveu “vacina”, dentista se escreveu “dentista”, e assim por diante.
3. **Texto livre pode gerar mais de um apoio.** “Vir em jejum e trazer Cartão SUS” pode exibir jejum + Cartão SUS.
4. **Sem correspondência segura, não inventar.** É melhor não mostrar pictograma do que mostrar um símbolo enganoso.
5. **Data e hora nunca viram apenas imagem.** Calendário e relógio são reforço; o valor exato permanece escrito.
6. **Dose, medida, diagnóstico e instrução clínica nunca são inferidos por pictograma.** A imagem apenas reforça texto já fornecido.
7. **Mesma ideia, mesma imagem em todo o site.** A biblioteca é central e compartilhada.
8. **Sem persistência.** A biblioteca é estática e os dados digitados nos módulos temporários continuam somente em memória.

## Teste de homologação visual

Para cada impressão com Apoio visual:

1. imprimir ou abrir a prévia;
2. cobrir mentalmente o texto principal;
3. perguntar o que a imagem comunica;
4. verificar se serviço, preparo, local ou ação podem ser reconhecidos;
5. se a interpretação puder levar a uma ação errada, remover ou substituir o pictograma;
6. repetir com uma pessoa que não participou do desenvolvimento, sempre que possível.

## Próximas ampliações da biblioteca

A biblioteca deve crescer conforme surgirem necessidades reais, sem criar imagens por adivinhação. Prioridades prováveis:

- sala de vacina;
- aferição de pressão;
- pesagem/medição de criança;
- saúde bucal preventiva;
- coleta de sangue e coleta de urina separadas;
- mamografia e citopatológico quando houver material específico;
- documentos e itens locais cuja forma seja reconhecida pela comunidade;
- preparo específico de exames somente após validação técnica.
