# Pictogramas de apoio à prescrição

Os oito arquivos em `src/assets/prescription-support/` são ilustrações originais geradas para o Território Vivo. As capturas do Cuidado Para Todos foram usadas somente para compreender a função do produto; nenhum desenho, logotipo, código ou recorte do site externo foi incorporado.

## Conjunto inicial

- Períodos: manhã, almoço, noite e antes de dormir.
- Vias: oral, injeção, uso na pele e gotas.
- Formato: PNG, 512 × 512 px, fundo transparente.
- Direção visual: pictogramas acolhedores, contorno azul-escuro, formas simples, alto contraste e sem texto embutido.

Dose, quantidade, intervalo e duração permanecem como texto editável ao lado dos pictogramas. Isso evita que uma imagem genérica seja confundida com uma instrução clínica exata.

## Limites de uso

Os pictogramas são apoio de comunicação. Não substituem a receita original, a orientação profissional, a conferência de dose, via, frequência, duração ou observações.
